# Site fonts

Self-hosted Latin WOFF2 files for Fira Sans (400, 500, 600, 700) and Fira Code (400, 600).
Downloaded from the official Google Fonts CSS service on 2026-10-07. No runtime Google Fonts requests.

Source stylesheet: https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;600&family=Fira+Sans:wght@400;500;600;700&display=swap

License sources:
- https://github.com/google/fonts/blob/main/ofl/firasans/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/firacode/OFL.txt

Keep both OFL license files with the font files when publishing. Local `css/fonts.css` preserves the source Unicode ranges; other characters use the site's fallback fonts.
